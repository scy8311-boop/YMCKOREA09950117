01 · CORE FEATURES

Lab-scale 정제에서
필요한 기능을 한 곳에.

LC-Forte/R-II는 다양한 컬럼과 정제 모드에 대응하면서 운전 편의성과 Recycling 기반 고효율 분리를 함께 제공합니다.

⟳

Recycling Purification

분리가 어려운 시료를 컬럼에 반복 통과시켜 높은 분리 효율을 확보하도록 지원합니다. 컬럼이나 이동상 조건을 변경하지 않고 분리도를 높이는 데 활용할 수 있습니다.

⇥

Stacking Injection

펌프 흡입 방식의 Stacking Injection과 Manual Injection을 지원해 동일 시료의 연속 주입 및 다양한 실험 구성이 가능합니다.

◫

Preview Function

크로마토그램을 확인하면서 정제 방법을 직관적으로 검토할 수 있도록 설계된 Preview Function을 제공합니다.

⚙

Manual / Auto Mode

Injection, Recycling, Fraction 운전을 Manual 또는 Auto 방식으로 구성할 수 있어 반복 정제 업무의 편의성을 높입니다.

⌁

Auto Replay & Cleanup

Auto Replay와 유로 자동 세척, 단계별 컬럼 세척 기능으로 반복 실험과 장비 관리 프로세스를 효율적으로 운영할 수 있습니다.

◉

Compact All-in-One

검출기를 본체 내부에 수납하는 컴팩트한 설계와 표준 컬럼 홀더를 갖춘 Lab-scale 장비입니다.

02 · RECYCLING

한 번의 분리로 부족할 때,
Recycling으로.
